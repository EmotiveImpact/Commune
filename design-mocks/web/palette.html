Commune · Colour palette

Deep green, navy green, signal red

The definitive brand palette — built on a deep forest green as the brand, a navy-green for dark surfaces, and a strong red for owe / overdue. Confident like a good fintech app: colour carries intent, not decoration — but the brand greens are present and saturated, never greyed out. Every token below maps to a --commune-* CSS variable.

Usage & restraint

Colour = intent. The brand greens should be present and confident — but never sprinkled as decoration.
Forest green is the brand. Primary buttons, active nav, key headings, links, focus, selected rows. Be confident — saturated, not a washed pastel.
Navy forest carries weight. Sidebar, auth brand panel, dark hero, profile menu. Raised bits inside use Navy Forest Soft.
Red is status only. Owe, overdue, destructive. Keep it rare so it reads as an alarm and actually means something.
Success ≠ brand. Settled / paid uses the cooler, lighter Success Green so a "paid" badge never looks like a primary button.
Numbers stay neutral ink. Totals and tables on ink for AA contrast; the status hue lives in the chip beside the number, not in the number.
Status chips are tint + text. Background *-bg, text the base hue, optional *-border — full fills are for the one destructive button only.
