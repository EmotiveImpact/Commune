Member detail

Two heroes: identity, then balance

Avatar + name says who. Sage hero card answers what's the situation. Action bar gives the three things you'd actually do here.

The principle

Consistency is the shell. Distinctiveness is the content. Same palette, same surfaces, same grid — but each screen type leads with its own landmark so the user always knows what kind of screen they're on, even at a glance.

Detail = hero a number

Group balance, total spent, who owes whom. The screen exists to answer one question — give that answer huge.

List = scan, don't read

Right-aligned balance pills with three colours. Decision-making happens on the right edge before users read titles.

Form = lead with intent

The amount IS the form's purpose. Make it gigantic at the top so the form's identity is unmistakable on first paint.

Flow = one question, one CTA

Progress dots. One headline. One input. One Continue button. Strip everything else — flows fail when they ask two things at once.
