Commune — Final v2

Updated mockups with audit fixes applied. Same visual language as recommended.html + remaining-screens.html, but with the gaps closed: emoji onboarding tiles replaced with Tabler icons, Settle up renamed and built, dead Save action removed from Group hub, Mark-as-paid CTA pinned outside scroll, unified palette across charts, Tabler icons everywhere.

What changed from v1

  • Onboarding — type tiles now use Tabler glyphs in coloured tiles (no emoji), one consistent rule across the app.
  • Settle up — explicit screen (renamed from Command Centre). Net-balance hero + smart-suggest card + per-person Pay/Remind rows.
  • Group hub — Save action removed. Edits route via the row-tap to /group-edit; the dead disabled button is gone.
  • Notifications — icons swapped from Ionicons outline to Tabler glyphs (CreditCard / CircleCheck / User / Refresh).
  • Analytics — single accent palette: sage primary, sage-light secondary, cream tertiary across donut + bars. No lime/navy split.
  • Expense detail — Mark-as-paid CTA pinned in a bottom bar outside the scroll.
  • Bottom sheet — one canonical pattern: 40×4 grab handle, 18px radius top, divider rows, no decorative close buttons.
