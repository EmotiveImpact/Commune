Sub-screen variants

For the 5 high-priority screens, here are 3 composition variants each — all following current mobile UX best practices (scannable rows, one primary action, date grouping for temporal data, empty states as nudges). Pick a direction per screen.

1 · Notifications

Opened from the bell. Users want to triage fast.

N1 Inbox (recommended)

Single list, date-grouped, unread highlighted

Default inbox pattern (Gmail / iOS Mail). Unread items use a subtle sage fill so they pop without being noisy. "Mark all read" top-right.
