# Commune — Design mockups

Static HTML mockups built while iterating on the mobile app redesign. Open any file directly in a browser to view.

| File | What it shows |
|---|---|
| [header-variants.html](./header-variants.html) | Header style options (A–E + baseline) |
| [header-left.html](./header-left.html) | 12 variants of the header's left-side element (menu / group switcher / search / etc) |
| [all-screens.html](./all-screens.html) | 3 variants each for Home / Expenses / Groups / Profile |
| [fix-audit.html](./fix-audit.html) | Audit of sub-screens that needed redesign, ranked by priority |
| [subscreen-variants.html](./subscreen-variants.html) | 3 variants each for Notifications / Settle up / Analytics / Recurring / Activity |
| [recommended.html](./recommended.html) | The synthesised "best of" single design per screen — Notifications · Settle up · Analytics · Recurring · Activity |
| [remaining-screens.html](./remaining-screens.html) | Recommended designs for Group hub · Member profile · Expense detail · New expense · Onboarding |

These are the source of truth for the mobile redesign. When live code diverges from a mockup, the mockup is the target.
