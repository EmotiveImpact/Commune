Remaining screens · recommended designs

One synthesised design per screen. Each follows the house rules: hero speaks to the next action, single primary CTA per view, temporal grouping where relevant, Tabler icons, avatar-led rows for social contexts, cream bg with dark-ink hero accents.

1 · Group hub (/group-hub)

Purpose: settings for the currently-active group (name, type, members, policies, danger zone). Fix: "Edit profile" on the Profile page currently routes here — wrong destination. Point Edit profile at a real profile editor; make this screen purely group-admin. Dark-ink hero shows the group identity, grouped rows below for each settings area.

2 · Member profile (/member-profile)

Purpose: tap a member on the Groups tab to see their activity, balance, and chores in this group. Design: Profile page P-B hero, but for another person. Social-feeling with Venmo-style stats. Secondary context rows follow — their balance with you, their recent activity, their share of chores.

3 · Expense detail (/expenses/[id])

Purpose: single expense view. Most-viewed power-user surface. Design: dark-ink amount hero with status pill; key facts (who paid, when, category) as compact rows; a clean split table showing each participant's status. Actions (Mark paid, Edit, Delete) pinned at the bottom so they don't scroll away.

4 · New expense (/expenses/new)

Purpose: add a shared cost fast. Design: amount-first — big number-pad-friendly input at the top (the field users fill 100% of the time). Everything else is inline form rows with sensible defaults so you can save after typing just the amount. Scroll-to-reveal advanced options.

5 · Onboarding (/onboarding)

Purpose: first-run setup — create a group, name it, invite people. Design: one decision per screen (not a multi-field form). Progress dots show where you are. Each step has a focus-stealing dark-ink hero that frames the question + a single primary CTA. Skip is always available.
