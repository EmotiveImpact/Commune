Commune — Onboarding v4

A deeper onboarding that introduces the product before asking for setup. Eight screens, three acts: sell (1–4), acquire attribution (5), setup (6–8). Every screen has explicit Back + Skip controls in the safe area, dot-indicators between, and a pinned Continue CTA at the bottom. Web mirrors the sell + acquire screens via a split-pane layout so the brand carries across both surfaces.

Key decisions

  • No paper-fold library. Build screens 1–4 with react-native-pager-view + reanimated dot-indicator. Screens 5–8 are stacked navigation. ~80 lines of new code, full design control, no stale deps.
  • Explicit Back + Skip in the top safe-area row. Back hides on screen 1; Skip text changes from "Skip" (sell screens) to "Skip step" (setup screens) to "Done" (final).
  • Illustrations, not the dark hero. Each sell-screen has a coloured tinted card with a floating product chip + iconography. Warm, editorial, never flat.
  • Reframe the starter pack. Toggle copy: "Skip the empty start" + "You can rename, add, or remove anything later."
  • Acquisition step is optional + skippable with a "Prefer not to say" tile. Captured to profiles.acquisition_source (needs a one-line migration).

Implementation notes

Acquisition source storage. Add column acquisition_source TEXT to profiles via a 1-line migration. Save as enum-ish string (tiktok | instagram | search | reddit | friend | app_store | youtube | other | null). Useful for future filtering.

Pager mechanics. Use react-native-pager-view for screens 1–4 (already Reanimated-3 compatible). Bind currentPage to the dot-indicator. Screens 5–8 are stacked navigation steps as today.

Back / Skip semantics. Back: hidden on screen 1; otherwise pops to previous step (pager goes left). Skip: visible on screens 1–5 (jumps straight to step 6). Replaced with "Skip step" on screen 8 (skips invite). Final CTA is "Open Commune" → routes to /(tabs).

Web parity. apps/web/src/routes/_app/onboarding.tsx rebuilds with the same 8-step state machine, but rendered as a split-pane (2fr / 3fr): left = illustrated panel from mobile sell screens; right = active step. Top bar inside the right panel carries Back/Skip buttons.

Illustrations. The four sell-screen "illustrations" in this mock are hand-drawn with floating product cards. Production version: commission a four-piece illustration set OR use a Lucide / Storyset / unDraw kit and tint to our palette. Budget for ~$200 if commissioning, free if curating.
